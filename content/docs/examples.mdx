# Common workday workflows

## Add a new recurring role

1. Browse the co-worker catalog.
2. Review what the role needs and returns.
3. Hire and configure it.
4. Run **Test now**.
5. Review activity and evidence.
6. Set a weekly schedule after the result is acceptable.

## Investigate a surprising result

1. Open the co-worker from **My Team**.
2. Read the latest activity and result.
3. Open the evidence.
4. Check the configuration and recent inputs.
5. Ask a focused question in chat if available.
6. Pause its schedule while you correct the issue, then test again.

## Temporarily stop a role

Use **Pause schedule** when you want to keep the schedule for later. Use **Archive** when the co-worker should leave My Team but you want to retain its history. Use permanent removal only after you are certain the record is no longer needed.
