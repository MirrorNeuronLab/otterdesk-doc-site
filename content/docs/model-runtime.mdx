# Use local AI

Some co-workers use local AI capabilities as part of their mission. OtterDesk keeps those details in the background and presents the parts you need to supervise: whether the co-worker is ready, what it is doing, and what it produced.

## What to review

Before relying on a result, review the co-worker's mission, recent activity, evidence, and limitations. Local AI does not remove the need for human judgment, especially for important decisions.

## Test before scheduling

Use **Test now** after configuring a co-worker that uses local AI. Review the output while the work is still narrow and easy to correct. Once it behaves as expected, set a schedule.

## When local AI is unavailable

Read the visible status and check runtime health. A resource or runtime issue can prevent a co-worker from starting. See [Runtime health](/docs/runtime-architecture) and [Resources and capacity](/docs/resources-and-devices).
