# Test a co-worker

**Test now** is the safe, manual way to start a co-worker run. Use it after hiring, after configuration changes, or when you want to check a role before scheduling it.

## Start a test

1. Open the co-worker in **My Team**.
2. Confirm it is configured.
3. Select **Test now**.
4. Open **Review work** or the status view to follow progress.
5. Inspect the result, evidence, and any decision request.

While a test is active, the action changes to **Pause test**. Pause when you need to stop the current work and reassess; use **Test now** again when you are ready to start a fresh run.

## Optional test substitutes

In **Settings → General → Quick testing**, you can turn on **Use a test model** or **Use test skills**. These substitutions affect only runs you start with **Test now**. They never affect scheduled shifts.

Use test substitutes to verify the workflow and review experience without relying on live model or skill behavior. Turn them off before validating a real-world result.

## After the test

If the result is right, set a regular schedule. If not, update the co-worker's configuration, then test again. See [Review work](/docs/monitor) and [Set schedules and shifts](/docs/schedules-and-events).
