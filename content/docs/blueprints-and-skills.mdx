# Browse and hire co-workers

The **Hire a co-worker** area is your catalog of available roles. Use it when you want to add a new capability to your team.

## Find the right role

1. Select **Hire a co-worker** in the sidebar.
2. Filter by category or use **Search co-workers**.
3. Select a co-worker to open its detail page.

The detail page tells you what to expect:

| Detail | Why it matters |
| --- | --- |
| Mission and benefit | The role and value the co-worker is intended to provide. |
| You provide | The information or setup it needs from you. |
| You receive | The result you can expect to review. |
| How it works | A plain-language description of its approach. |
| Requirements | Hardware or runtime needs, such as a GPU. |

## Hire safely

Select **Hire Co-worker** from the catalog or the detail page. OtterDesk checks whether the available runtime can support the co-worker before adding it. If a requirement is not met, resolve that requirement first; see [Resources and capacity](/docs/resources-and-devices).

When hiring finishes, open **My Team**. The next useful action is usually **Configure**, followed by **Test now**.

## Already on your team

Catalog entries show **On your team** when you have already hired that co-worker. Select **Open team** to go directly to it.

See [Choose a co-worker](/docs/blueprint-standard) for a decision checklist.
