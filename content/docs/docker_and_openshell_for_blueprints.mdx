# Set up your local runtime

OtterDesk uses Docker Desktop to run the local runtime on your computer. Docker gives the runtime the isolated environment it needs for co-worker work.

## First-time setup

When you first open OtterDesk, it checks Docker and prepares the local runtime automatically when possible. Keep OtterDesk open while this happens.

## If Docker is needed

1. Install Docker Desktop.
2. Open Docker Desktop and wait until it is fully running.
3. Return to OtterDesk.
4. Choose **Try again**.

The app continues once Docker is ready. The setup dialog includes a short log and may take several minutes on first use.

## Give Docker enough resources

If a co-worker needs more CPU or memory, change Docker Desktop settings under **Settings → Resources → Advanced**. Then reopen **OtterDesk → Settings → Resources** to review reported capacity.

For GPU needs or additional computers, see [Resources and capacity](/docs/resources-and-devices).
