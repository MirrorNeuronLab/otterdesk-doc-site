# Check your setup

When OtterDesk cannot hire, start, or schedule a co-worker, check the basics in this order.

1. Make sure OtterDesk is open and current.
2. Confirm Docker Desktop is installed and running.
3. Open **Settings → Resources** and check runtime and API status.
4. Review the co-worker's hardware requirements.
5. Confirm the co-worker is configured.
6. Run **Test now** and review the message if it fails.

## What to include when asking for help

Describe the action you tried, the co-worker involved, the visible status, and the safe error message shown in OtterDesk. Do not share passwords, federation tokens, or private source material.

For fixes organized by symptom, read [Troubleshooting](/docs/troubleshooting).
