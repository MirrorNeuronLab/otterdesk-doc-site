# Troubleshooting

## OtterDesk says Docker is needed

Install Docker Desktop or open it if it is already installed. Wait until Docker is ready, return to OtterDesk, and select **Try again**. See [Set up your local runtime](/docs/docker_and_openshell_for_blueprints).

## A co-worker cannot be hired

Review its requirements on the detail page. Check **Settings → Resources** for available capacity. If it needs a GPU you do not have, add a suitable trusted computer or choose a different co-worker.

## A co-worker cannot start

Confirm the co-worker is configured, check runtime health, then select **Test now** again. Read the displayed message before retrying.

## A schedule did not run

Open **Shifts**, refresh the page, and verify that the schedule is enabled. Check for a schedule error and confirm the runtime is ready. If you recently changed capacity or connected computers, review **Settings → Resources**.

## Chat says current work is limited

The co-worker can still offer role or planning guidance, but OtterDesk cannot verify current work at that moment. Use the ordinary status and review controls, or check runtime health.

## I need more help

Record the co-worker name, the action you tried, the visible status, and the safe error message. Do not include passwords, tokens, or private material in a support request.
