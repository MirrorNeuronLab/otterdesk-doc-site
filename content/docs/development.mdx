# Advanced setup help

Most OtterDesk tasks should be completed from the app: hire, configure, test, review, schedule, or archive a co-worker.

Ask an administrator or support for help when you need to:

- Install or repair Docker Desktop.
- Change the computer's hardware allocation.
- Prepare another computer for the shared resource cluster.
- Resolve a persistent local runtime setup problem.
- Install an OtterDesk update that your computer does not permit.

When you ask, share the visible message and the actions you already tried. Keep credentials and private data out of the request.

For common recoverable problems, start with [Troubleshooting](/docs/troubleshooting).
