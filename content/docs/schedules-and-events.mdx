# Set schedules and shifts

Use a schedule when a co-worker has passed a reviewable test and needs to run regularly. You can set a schedule from a co-worker in **My Team** or from the **Shifts** view.

## Create a weekly schedule

1. Open the co-worker.
2. Select **Set schedule**.
3. Leave **Weekly schedule** selected.
4. Choose the days and a duration.
5. Choose **Auto-schedule** to let OtterDesk avoid other active windows, or **Choose time** for an exact half-hour start.
6. Make sure the schedule is enabled, then select **Save schedule**.

## Use a cron expression

Choose **Cron expression** when you need a more exact repeating pattern. OtterDesk accepts five fields: minute, hour, day of month, month, and day of week.

For example, 0 9 * * 1-5 means weekdays at 9:00 AM. Use cron only when a weekly window cannot express the timing you need.

## Pause or change a schedule

Select **Pause schedule** to keep the saved timing but stop future automatic starts. Open the schedule again to update the days, time, duration, or enabled state.

After a schedule runs, use [Review work](/docs/monitor) to inspect the outcome. Scheduled shifts never use the optional test substitutes from **Quick testing**.
