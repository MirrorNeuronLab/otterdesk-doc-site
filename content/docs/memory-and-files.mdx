---
title: Memory and files
description: Browse co-worker files, inspect saved instructions, and understand what clearing Chat removes.
---

A conversation, saved instructions, domain knowledge, and run files serve different purposes. Changing one does not automatically erase the others.

## Browse input and output files

1. Open the co-worker's Chat.
2. Select **Show workspace panel**, then **Files**.
3. Expand **Input** or **Output**, filter loaded files, and select a file.
4. Use **Refresh files** to read current contents.

The preview is read-only for supported text and images. **Expand file preview** gives it more panel space. **Open files in separate window** moves the browser and preview to a resizable window; close it or choose **Return files to workspace** to bring the same selection back.

**No input folder** means there is no local input folder available for this co-worker. It does not mean the co-worker has no other configured source. Large or unsupported files may need the co-worker's own report tools or a native application.

## Review saved instructions

In the workspace panel, select **Memory**. Where supported, **Saved instructions** separates:

| Instruction | Where it applies |
| --- | --- |
| Explanation preference | How the co-worker explains its work in Chat. |
| Working rule, where offered | How it works on the next run. |

Choose **Remember an instruction**, select the available scope, write the instruction, and **Save changes**. Existing entries offer **Edit** and **Forget**. Check any pending-setup or waiting-to-sync message before assuming a rule is active.

Some co-workers keep their memory in dedicated knowledge or rule controls instead. Follow that message; the Memory panel is not a universal editor for every internal state. Domain rules, approvals, and active-run settings retain their own controls.

## Know what persists

| Data | How to manage it |
| --- | --- |
| Chat messages and saved evidence previews | Inspect in Chat; use the confirmed **Clear chat** action for conversation history. |
| Explicit saved instructions | Edit or forget them in Memory where supported. |
| Inputs, outputs, reports, and domain knowledge | Inspect Files and the co-worker's knowledge/report controls. |
| Co-worker configuration and credentials | Use Configure and its secure fields. |
| Archived runtime work and retained checkpoints | Review archive/storage controls; permanent deletion is separate. |

Clearing Chat does not restart onboarding, remove a co-worker, or erase its runtime files and knowledge. Archiving retains historical data. If you need portable runtime data, use [Backup and restore](/docs/backup-and-restore).
