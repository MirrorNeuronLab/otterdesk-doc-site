# Privacy and safety

OtterDesk is a local-first desktop app. It is designed to keep routine supervision in the app while limiting what the user interface can directly access.

## Keep secrets private

Do not paste passwords, access tokens, or federation tokens into chat, notes, or documentation. When OtterDesk asks for a federation token while adding a computer, it treats the token as private and does not show it in logs.

## Review connections

Only connect data sources, Slack channels, and computers that are appropriate for the co-worker's mission. Revisit connections whenever a co-worker's responsibility changes.

## Use approvals

Respond thoughtfully to **Decision needed** cards. Approval is a supervisory choice, not a routine click. Read the prompt and evidence, add notes when useful, and reject or request revisions when the proposed action is not right.

## Remove access when it is no longer needed

Pause a schedule, remove an integration route, archive a co-worker, or permanently remove it when its role ends. See [Archive, remove, and update](/docs/deployments).
