---
title: Approvals and requested input
description: Answer the request in Respond, preserve its scope, and review rule collections before approval.
---

Co-workers can ask for setup input, a choice, a reply, or a formal review. Chat keeps the context in the transcript and the active controls in **Respond** at the bottom.

## Answer the selected request

1. Read the request and the result or evidence it refers to.
2. Select **Respond** if you are in Message mode.
3. If several requests are waiting, select the correct one.
4. Add optional notes when they help explain your decision.
5. Choose one of the actions the co-worker actually offers.

| Choice, when offered | Meaning |
| --- | --- |
| **Approve** | Record approval for the specific proposal. |
| **Reject** | Reject that proposal. |
| **Request changes** or a revision choice | Record the request for changes, with notes where appropriate. |
| A named option | Answer the particular choice described by the co-worker. |
| Text response and submit action | Provide the requested answer in your own words. |

Available choices come from the request. An approval button is not guaranteed. A single choice can submit immediately; forms and multiple selections have a separate submit action. After submission, check the decision receipt. If it failed, keep the draft and resolve the error before trying again.

## Understand what your choice authorizes

Read the wording carefully. A decision can record review without revising a report, restarting work, or triggering a follow-up task. Discussion in Message mode does not substitute for the formal request. Expired or already handled requests cannot be assumed to remain actionable.

For a setting proposal, review the proposed values before applying it. For schedule help, review the exact timing and next occurrence before saving. For failed work, inspect the separate retry plan before submitting it.

## Review a Markdown rule collection

Some co-workers request review of a titled rule list. You can search the complete list, select a rule, inspect source references, edit it, preview the result, and save.

**Approve all approves the entire saved collection, even when search filters the visible list.** Save or discard open edits first. A failed save keeps your draft and blocks approval. Approval applies to the saved revision shown by the request.

If you are unsure, inspect the source, ask a focused question, or use the offered revision/rejection path. See [Review work](/docs/review-work).
