# Find your way around OtterDesk

OtterDesk keeps the main supervision actions close together.

| Screen | Use it for |
| --- | --- |
| Hire a co-worker | Browse roles, inspect their expectations, and hire one. |
| My Team | Open a co-worker, test it, chat, configure it, or review its work. |
| Shifts | See scheduled coverage, refresh schedules, and adjust timing. |
| Settings | Manage preferences, archived co-workers, resources, runtime checks, and updates. |

## The usual path

Most work follows this order:

**Hire a co-worker → Configure → Test now → Review work → Set schedule**

You can return to any point in that loop. Use **My Team** as the daily starting place after your first co-worker is set up.
