# Use a shared resource cluster

When you connect another PC, OtterDesk can show the combined capacity of your trusted computers. This is useful for matching co-workers to the resources they need.

## What a connected computer adds

A connected computer contributes its reported CPU, GPU, and memory capacity. OtterDesk uses that information when checking whether a co-worker can be hired and run.

## What remains local

Each computer keeps its own local runtime and health state. A connected computer is not a replacement for reviewing the co-worker's actual status and evidence in OtterDesk.

## Good practices

- Connect only computers you trust and can maintain.
- Keep Docker Desktop running on each participating computer.
- Review **Settings → Resources** after changing hardware or Docker allocations.
- Leave a computer from the resource view when it is no longer available to your team.

Use [Connect another PC](/docs/cluster) for the setup steps and [Resources and capacity](/docs/resources-and-devices) to review capacity.
