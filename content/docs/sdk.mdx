# Use Slack with a co-worker

Eligible co-workers can be connected to Slack so messages in a mapped channel reach that co-worker when its local response service is ready.

## Connect a channel

1. Open the co-worker and go to its integration area.
2. Connect OtterDesk to Slack if prompted.
3. Create a new channel or choose an existing one.
4. Save the route for that co-worker.

The integration view shows the current workspace routes so you can confirm which channel belongs to which co-worker.

## Manage the route

Update the route when the co-worker's responsibility changes. Remove it when the co-worker should no longer receive Slack messages.

Before enabling a route, review the co-worker's mission and data boundaries. Keep private or unrelated conversations out of channels connected to a co-worker.

For supervision after a message reaches the co-worker, use [Review work](/docs/monitor) and [Chat with a co-worker](/docs/cli).
