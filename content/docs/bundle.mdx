# Configure a co-worker

After hiring a co-worker, open it from **My Team** and choose **Configure**. Configuration makes it easier to recognize the role and supplies the information it needs for safe work.

## What to configure

Depending on the co-worker, you may be able to set:

- A display name or alias.
- An avatar.
- Mission-specific settings.
- Required connections or non-secret values.
- A workspace folder, when the co-worker uses one.

OtterDesk shows only the configuration relevant to that co-worker. Save changes before starting a test.

## Good configuration habits

- Use a clear, role-based name, such as “Daily operations review.”
- Make the mission-specific inputs precise and current.
- Review any stated data access or limitation before saving.
- Test after each meaningful change.

## If configuration cannot be saved

Read the message in the app and correct the highlighted value. If the issue persists, check that the local runtime is healthy, then try again. See [Runtime health](/docs/runtime-architecture) and [Troubleshooting](/docs/troubleshooting).
