OtterDesk opens to **My Team**. The sidebar keeps your hired co-workers available while you inspect their conversations and work.

## Main surfaces

| Surface | Use it for |
| --- | --- |
| **Hire a co-worker** | Search the catalog, inspect requirements and trust details, and hire a role. |
| **My Team** heading | Compare team members and their recorded performance. Select a card header for Chat; select measurements for Performance. |
| A co-worker in the sidebar | Open that co-worker's contextual Chat. **Running only** filters the list; **Show everyone** clears the filter. |
| **Collaboration** | Configure compatible co-workers around a shared goal. Saving a board does not start work. |
| **Settings** | Open General, Archived, Resources, and Updates. |
| **Help** | Open this guide. |
| Account button | Sign in or inspect your connected account and balance. |

## Co-worker details

From Chat, select **View details** in the toolbar. Hover over icon buttons to see their tooltips. Details include:

- **Overview:** mission, saved context, status, and advanced run identifiers.
- **Performance:** recorded running time, tokens, and run outcomes.
- **Configure:** saved inputs and settings; **Save changes** does not start work.
- **Status:** workflow steps, graph, and run assignment.
- **Shifts:** this co-worker's schedule and calendar.
- **Inputs & outputs:** available run inputs and results.
- **Integration:** supported Slack and external AI connections.
- **Logs:** detailed activity for investigation.

Schedules live inside the relevant co-worker's **Shifts** tab. There is no team-wide Shifts navigation item.

## Workspace and bottom bar

In Chat, **Show workspace panel** opens supporting views such as progress, Web UI, Files, and Memory where supported. Hide it to give the conversation more space.

**Quick view** in the bottom bar lets you inspect running and queued work. Nearby controls show notifications and **Core status**. The header's resource readings measure the computer or cluster, including other applications; they are not a per-co-worker progress bar.

Use the sidebar's back and forward arrows to revisit surfaces. The command palette provides another route to app actions.
