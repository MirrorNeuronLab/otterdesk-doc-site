Open **Settings** in the sidebar. Common choices appear first; infrequent controls are in expandable sections.

## Settings sections

| Tab | What to inspect |
| --- | --- |
| **General** | Appearance, desktop notifications, anonymous usage statistics, account credits, and expandable backup/restore and conversation-testing controls. |
| **Archived** | Archived co-workers, their history, restoration, and permanent deletion. |
| **Resources** | This computer, connected computers, capacity, connection details, and runtime/API health. |
| **Updates** | The available update preference controls. Desktop installation remains a separate action. |

## Appearance and notifications

Choose **Light**, **Dark**, or **Use system settings** for appearance. Under **System notifications**, **Show desktop notifications** controls native notifications. Your operating system's notification settings also apply.

Notifications normally appear while OtterDesk is in the background; selecting one opens the relevant co-worker. Routine banners are suppressed while the app is focused. The current interface does not expose category, timing, or quiet-hours editors.

## Privacy

Under **Privacy**, turn **Share anonymous usage statistics** on or off. It is enabled by default. Turning it off stops reporting and discards pending statistics. See [Privacy and safety](/docs/privacy-and-safety) for exactly what is included.

## Update OtterDesk

Use a current package from the [OtterDesk website](https://otterdesk.app) to install a newer desktop release. The Updates page does not automatically install the desktop app. Update matching MirrorNeuron components when an error specifically requires a newer runtime capability.

Back up important work before a version change that affects local data compatibility. Unsupported older desktop data is not silently migrated or deleted; see [Troubleshooting](/docs/troubleshooting).

## Advanced, infrequent actions

Use **Backup and restore** to transfer a saved runtime co-worker. **Test conversation** exercises the desktop conversation engine without a real co-worker's tools or durable history; it is not a test run of your hired co-worker. Runtime repair and diagnostics belong in Resources.

For mission-specific inputs, use the co-worker's **Configure** tab instead of app Settings.
