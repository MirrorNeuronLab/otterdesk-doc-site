# Quick start

This is the fastest safe way to get value from OtterDesk: set up the local runtime, hire one co-worker, configure it, and run a test you can review.

## 1. Open OtterDesk

On its first launch, OtterDesk checks whether the local runtime is ready. Keep the app open while first-time setup finishes. If OtterDesk asks for Docker Desktop, install and start Docker Desktop, then choose **Try again**.

See [Set up your local runtime](/docs/docker_and_openshell_for_blueprints) for more detail.

## 2. Hire a co-worker

1. Select **Hire a co-worker** in the sidebar.
2. Search or filter the catalog.
3. Open a co-worker to review its mission, what you provide, what you receive, and any hardware requirements.
4. Select **Hire Co-worker**.

OtterDesk checks the local runtime before it adds a co-worker. A co-worker with GPU requirements cannot be hired until a suitable computer is available.

## 3. Configure it

Open **My Team**, select your new co-worker, then choose **Configure**. Give it a recognizable name and complete any required non-secret settings. Save changes before you test.

## 4. Run a test

Choose **Test now**. Follow progress in the co-worker's status view, then review the activity, inputs and outputs, and any evidence it produced.

## 5. Choose the next step

- If the result looks right, choose **Set schedule** to create regular shifts.
- If the co-worker needs a different instruction or connection, choose **Configure** and test again.
- If it asks for a decision, answer from the decision card before it continues.

For a fuller walkthrough, see [Browse and hire co-workers](/docs/blueprints-and-skills), [Configure a co-worker](/docs/bundle), and [Review work](/docs/monitor).
