# Performance and capacity

Co-worker performance depends on the mission, configured inputs, local runtime health, and available CPU, GPU, and memory. OtterDesk presents capacity so you can make practical decisions without tuning internal services.

## Check before adding more work

Open **Settings → Resources** and review:

- CPU capacity.
- GPU capacity.
- Memory capacity.
- Capacity currently in use by the selected co-worker.

## Improve reliability before speed

Before adding more co-workers or longer shifts:

1. Test one role at a time.
2. Review its result and duration.
3. Avoid overlapping schedules when resources are limited.
4. Add a trusted computer if a role needs hardware you do not have.

Choose a co-worker based on a clear mission and reviewable outcome, not only on speed. See [Choose a co-worker](/docs/blueprint-standard).
