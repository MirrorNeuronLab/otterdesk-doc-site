# Use this guide

This guide is written for people supervising co-workers, not for software developers.

## Find the right page

- Setting up for the first time: [Quick start](/docs/quickstart).
- Adding a role to your team: [Browse and hire co-workers](/docs/blueprints-and-skills).
- Checking results: [Review work](/docs/monitor).
- Running regular work: [Set schedules and shifts](/docs/schedules-and-events).
- Solving a problem: [Troubleshooting](/docs/troubleshooting).

## Read the action labels literally

OtterDesk uses direct labels:

- **Test now** starts a manual test.
- **Pause test** pauses an active test.
- **Set schedule** prepares recurring work.
- **Pause schedule** stops future scheduled starts.
- **Review work** opens activity, evidence, and results.
- **Archive** removes a co-worker from My Team while retaining its record.

If the label in your app differs, use the visible description next to it and choose the least destructive action while you investigate.
