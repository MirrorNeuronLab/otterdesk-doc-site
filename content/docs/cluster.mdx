# Connect another PC

Connect another computer when your current computer does not have enough capacity for a co-worker, especially when a co-worker requires a GPU.

## Before you connect

The other computer must be trusted, reachable from this computer, and prepared with its own local runtime. Do not connect a computer you do not control.

## Add the computer

1. On the other computer, start its runtime with the mn runtime start command.
2. Copy the host address and federation token shown by that command.
3. In OtterDesk, open **Settings → Resources**.
4. Select **Add computer**.
5. Enter the computer address and paste the federation token.
6. Select **Add computer**.

The token is private. OtterDesk treats it as a password and does not show it in logs.

## After it connects

Switch to **Full cluster** in **Settings → Resources** to review combined capacity. You can then retry hiring or scheduling a co-worker whose requirements could not be met locally.

If connection fails, confirm that the computers can reach one another, then check [Runtime health](/docs/runtime-architecture).
