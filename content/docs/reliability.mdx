# Understand co-worker status

OtterDesk uses short, consistent labels to show the current supervisory state of a co-worker.

| Status | Meaning | Useful next step |
| --- | --- | --- |
| Ready | The co-worker is available but is not working right now. | Test it or set a schedule. |
| Running | A test or scheduled run is in progress. | Review activity or pause the test if needed. |
| Scheduled | Future work is planned on an enabled schedule. | Review the next shift or pause the schedule. |
| Paused | A test or schedule has been intentionally stopped. | Resume by starting a test or enabling the schedule. |
| Needs review | A result, failure, or decision needs your attention. | Open the co-worker and review its activity and evidence. |

Status is a starting point, not a complete explanation. Open the co-worker to see the latest activity and the next safe action.

For a full review routine, see [Review work](/docs/monitor).
