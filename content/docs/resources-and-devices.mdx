# Resources and capacity

OtterDesk reports the CPU, GPU, and memory capacity available to your local runtime. Use this view when a co-worker has hardware requirements or when several co-workers need to run regularly.

## View capacity

Open **Settings → Resources**. Choose:

- **This computer** to see the local computer's reported capacity.
- **Full cluster** to see capacity across connected computers.

The page shows CPU slots, GPU slots, and memory, along with the selected co-worker's current use.

## Change capacity

OtterDesk reports resource availability but does not change it directly. To change CPU or memory allocation, open **Docker Desktop → Settings → Resources → Advanced** on the relevant computer. Update each computer separately when you use a cluster.

## Solve a hardware requirement

If hiring reports that no computer meets a co-worker's GPU requirement:

1. Confirm the requirement on the co-worker detail page.
2. Check available capacity in **Settings → Resources**.
3. Adjust Docker Desktop resources if appropriate.
4. Or [connect another PC](/docs/cluster) with suitable hardware.

After the requirement is met, return to the catalog and hire the co-worker.
