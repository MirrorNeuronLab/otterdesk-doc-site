Get the current download from the [OtterDesk website](https://otterdesk.app). Choose the package that matches your operating system and processor.

## Choose your download

| Platform | Architecture and package |
| --- | --- |
| macOS | Choose Apple Silicon (ARM64) or Intel (x64), matching your Mac. |
| Windows | Choose x64 or ARM64. Use the installer for normal installation; ZIP packages are also available. |
| Linux | x64/amd64 and ARM64 builds use Debian packages or ZIP archives. Choose a package appropriate for your distribution. |

Use the requirements shown with the current release rather than assuming every older operating system is supported. Individual co-workers can require substantially more memory or a particular GPU.

## Before you open the app

Have network access for the initial app, runtime, blueprint, and model downloads. The runtime uses Docker; install and start Docker Desktop when setup asks for it. Allow enough disk space for models and co-worker outputs, which can be much larger than the app itself.

Install the downloaded package using your operating system's normal process, then open OtterDesk.

## What first launch does

The **Preparing OtterDesk…** window checks and prepares MirrorNeuron, the local runtime used for co-worker work. First setup can take a while. The main window opens after runtime readiness is confirmed.

If preparation fails, choose **Open install console** to inspect the failure. Correct the reported issue, then choose **Try again**. A failed download or installer run remains an error to resolve; repeatedly reopening the app does not fix it.

After the main window opens, two separate preparations may continue:

- **Default model** supports co-worker work and knowledge-backed replies. The runtime selects a compatible model when its configured default is missing.
- **Convo model** supports desktop guidance and setup. It is a separate CPU-only model, downloaded in the background. Its model file is about 1.67 GB, plus the inference engine.

The app remains usable during these background downloads, but some conversation features must wait. Inspect the **Core status** panel in the bottom bar for readiness.

## Sign-in is optional for free work

You do not need to sign in to reach My Team or use free local co-workers. Google sign-in is used for account features and paid access. See [Account and credits](/docs/account-and-credits).
