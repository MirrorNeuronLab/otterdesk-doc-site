# Install OtterDesk

Install the OtterDesk desktop app on the computer where you want to supervise co-workers. OtterDesk supports macOS and Windows.

## Before you begin

You need:

- A supported Mac or Windows computer.
- Permission to install desktop applications.
- Docker Desktop installed and running for the local runtime.
- Network access when downloading OtterDesk, the runtime, or a co-worker.

Some co-workers have additional CPU, memory, or GPU requirements. You can inspect these before hiring them.

## Install and open the app

1. Download the OtterDesk installer for your computer.
2. Run the installer and follow its prompts.
3. Open OtterDesk.
4. If prompted, install or start Docker Desktop.
5. Leave OtterDesk open while it prepares the local runtime.

The first setup can take several minutes. OtterDesk shows a short installation log while it works.

## If setup pauses

When the app says **Docker is needed**, install Docker Desktop or start it if it is already installed. Once Docker is ready, return to OtterDesk and select **Try again**.

When setup is complete, open [Quick start](/docs/quickstart) to hire and test your first co-worker.
