# Chat with a co-worker

Some co-workers support contextual chat. When available, select **Chat** from the co-worker's page to ask questions in the context of that role.

## Good questions to ask

- What are you responsible for?
- What did you notice in the latest work?
- What would you do next?
- What information do you need from me?
- Can you explain this evidence in plain language?

## What chat can and cannot confirm

When live work context is available, the co-worker can help explain current work and evidence. When it is not available, chat can still provide role and planning guidance, but OtterDesk marks current-work information as limited.

Do not treat chat as an unreviewed command channel. When a chat request could start a test run, OtterDesk asks for confirmation first. A pause request can act directly for the selected co-worker.

Use the ordinary co-worker controls for configuration, schedules, and review whenever possible.
